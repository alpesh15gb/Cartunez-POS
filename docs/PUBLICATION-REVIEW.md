# Public source publication review

Reviewed on 2026-11-16 for the initial public `alpesh15gb/Cartunez-POS` source publication. This review covers the Git candidate files, not ignored build folders or the separate delivery archives.

- The publication set contains application source, migrations, dependency lockfiles, deployment tools, tests, public assets and sanitized verification reports. Private environment files, generated dependencies, databases, backup dumps, installers, signing keys, local SDK settings and private configuration are excluded.
- Filename and text scans found no private-key material, literal access tokens, JWT sessions, credential-bearing database connection strings or absolute user-workspace paths in the candidate source. Compose connection strings use environment substitutions. Published password literals and account names are explicitly fictional development/test fixtures; production rejects demo seeding and requires separately configured bootstrap credentials.
- Test receipts and screenshots use fictional customers, suppliers, addresses and tax identifiers. Public certificate fingerprints and installer checksums are verification data; they do not include private signing keys. Android signing material remains outside the repository.
- The desktop icon (`apps/desktop/build/icon.ico`), Android Gradle wrapper JAR and launchers, migration files, environment example, root workspace lockfile and separate desktop lockfile are included. The ignore rules preserve these required source inputs.
- A disposable copy containing only candidate source passed `npm ci --workspace @motorline/android --include-workspace-root --ignore-scripts --no-audit --no-fund` and `npm run sync --workspace @motorline/android`. Capacitor regenerated the ignored Cordova support project, application configuration and bundled-assets directory. The app and instrumentation-test Java sources compiled successfully through `:app:compileDebugAndroidTestJavaWithJavac` (54 Gradle tasks). The template instrumentation assertion was corrected to the application's actual ID, `com.motorline.pos`. A minimal disposable HTML file was used only to test synchronization; this check did not install or replace an APK or rerun device UI acceptance. Complete package acceptance evidence is recorded separately.
- Android requires an installed JDK 21 and Android SDK 36. The convenience build command uses Windows `gradlew.bat`; Linux/macOS builders can run `./gradlew` from `apps/android/android` after installing dependencies, building the web export and running Capacitor sync. Native toolchains and credentials are intentionally not bundled. Browser tests permit `BROWSER_PATH`; their Windows Edge default is a test-machine convenience, not a deployed runtime dependency.

The 12 product thumbnails match the earlier prototype byte for byte. Its creation record identifies them as ImageGen-generated, unbranded automotive objects. The interface is original. Public [GoFrugal automotive POS information](https://www.gofrugal.com/retail/specialized-retail-pos/auto-parts-billing.html) and [RetailEasy hold/recall documentation](https://community.gofrugal.com/portal/en/kb/gofrugalretaileasyoncloud/sales-management/sales-bill/articles/how-to-1-11-2025-1) informed workflow behavior; no private GoFrugal implementation, logo or licensed parts/fitment database is included. Dependency licenses remain those of their respective packages.

This bounded publication scan complements the clean-checkout build and business acceptance tests; it is not a guarantee that every future edit is safe to publish. Keep live shop data, backup files, credentials and release-signing material outside Git. Initial publication does not change the existing delivery archives or their hashes.
